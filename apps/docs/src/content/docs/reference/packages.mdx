## Published Packages

| Package | Role |
| --- | --- |
| `@kairohq/cli` | Standalone CLI for local project memory. |
| `@kairohq/mcp` | MCP server for assistant integrations. |
| `@kairohq/ai` | AI provider, answer, and embedding helpers. |
| `@kairohq/core` | Observation, storage, reconstruction, search, and memory logic. |
| `@kairohq/shared` | Shared schemas and TypeScript types. |
| `@kairohq/utils` | Shared utility helpers. |

The web and desktop apps are built from the repository but are not published as npm packages.
