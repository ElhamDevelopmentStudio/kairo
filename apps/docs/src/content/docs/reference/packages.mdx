## Published Packages

| Package | Role |
| --- | --- |
| `@kairo/cli` | Standalone CLI for local project memory. |
| `@kairo/mcp` | MCP server for assistant integrations. |
| `@kairo/ai` | AI provider, answer, and embedding helpers. |
| `@kairo/core` | Observation, storage, reconstruction, search, and memory logic. |
| `@kairo/shared` | Shared schemas and TypeScript types. |
| `@kairo/utils` | Shared utility helpers. |

The web and desktop apps are built from the repository but are not published as npm packages.
