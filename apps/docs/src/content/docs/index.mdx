description: Local-first development intelligence for project memory.
---

Kairo observes development activity and turns it into searchable project memory.

Use the CLI by itself when you only need local observation and answers. Add the dashboard or desktop app later when you want a visual surface.

## What Kairo Gives You

- Session timelines from git, files, terminal activity, and optional agent transcripts.
- Searchable project memory for decisions, fixes, and architecture shifts.
- Optional MCP and dashboard surfaces over the same local workspace data.

## Install

```sh
npm install -g @kairohq/cli
kairo init
kairo sweep
```
