## Kairo Project Memory

Kairo is installed as this project's local memory layer. It observes project
activity and exposes stored evidence through the local Kairo MCP server.

When the user asks about project history, previous decisions, past fixes,
architecture changes, regressions, or why something exists, query Kairo before
answering. Prefer `kairo_ask` for direct questions, `kairo_search` for keyword
lookup, and session/detail tools when citations need inspection.

Use the host assistant's own reasoning to explain the result. Do not require a
separate Kairo AI provider unless the user explicitly enables one.
